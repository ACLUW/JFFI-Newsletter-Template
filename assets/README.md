# JFFI image assets

Replace these local assets with approved JFFI imagery, keeping the filenames used by the template:

- `jffi-logo.png`
- `hero-worship.jpg`
- `pastor-chibuzor.jpg`
- `event-1.jpg`
- `event-2.jpg`

`jffi-logo.png` is the public JFFI website logo downloaded from `https://www.jffi.org/logo.png`.
